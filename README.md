# RT Kita — Aplikasi RT Mandiri

Aplikasi web/PWA untuk Ketua RT dan warga. Tidak menggunakan Google Sheets.

Fitur:
- Login Ketua RT dan warga
- Database warga sendiri
- Dashboard
- Kas RT
- Pengajuan surat
- Pengaduan
- Pengumuman
- Bisa dipasang sebagai aplikasi di HP (PWA)
- Siap dideploy ke server dengan database persisten

Akun awal: admin / admin123 (ganti segera).
